# Aplicação de Segmentação de Objetos com YOLO26

Este projeto apresenta uma aplicação simples de segmentação de objetos utilizando a biblioteca Ultralytics e o modelo YOLO26.

Foi utilizado o dataset **COCO8-Seg**, disponibilizado pela Ultralytics, para realizar a segmentação de objetos em imagens.

## Objetivo

Aplicar um modelo de visão computacional para identificar e segmentar objetos presentes em uma imagem.

## Tecnologias

- Python
- Ultralytics
- YOLO26
- COCO8-Seg
- Google Colab

## Notebook

O notebook `YOLO26_Segmentacao_COCO8_Seg.ipynb` contém todas as etapas da aplicação, desde a instalação da biblioteca até a visualização dos resultados da segmentação.# Aplicação de Segmentação de Objetos com YOLO26
