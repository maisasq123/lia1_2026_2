# 🌸 Projeto 2 — Classificação de Flores com Inteligência Artificial

## 🌺 Sobre o projeto

Projeto de **Visão Computacional** desenvolvido para classificação automática de imagens de flores utilizando uma **Rede Neural Convolucional (CNN)**.

O modelo foi treinado com o dataset **Oxford Flowers 102**, contendo **102 categorias de flores**.

> 🌱 **Uma imagem. 102 possibilidades. Uma IA tentando descobrir qual é a flor.**

## 🎯 Objetivo

Construir um modelo capaz de analisar uma imagem de uma flor e classificá-la entre **102 categorias diferentes**.

## 🧠 Tecnologias

- Python
- TensorFlow
- Keras
- TensorFlow Datasets
- NumPy
- Matplotlib
- Scikit-learn

## 🔬 Pipeline

**📊 Dados → 🧹 Pré-processamento → 🔄 Data Augmentation → 🧠 CNN → 🚀 Treinamento → 🧪 Teste → 🔮 Inferência**

## 📚 Dataset

**Oxford Flowers 102**

- 🌸 102 categorias
- 📸 Imagens coloridas
- 🎯 Classificação multiclasse
- 🔬 Visão Computacional

## 🏗️ Modelo

A rede utiliza:

- 3 camadas convolucionais
- Max Pooling
- Global Average Pooling
- Camada Dense
- Dropout
- Softmax com 102 saídas

## 📊 Resultado

**Acurácia no conjunto de teste: 19,39%**

Como existem 102 classes, uma escolha aleatória teria aproximadamente **0,98% de acurácia**.

O projeto também inclui:

- 📈 Curvas de treinamento e validação
- 🧩 Matriz de confusão
- ❌ Análise dos erros
- 🔮 Top 5 previsões
- 🌐 Testes com imagens externas da internet
